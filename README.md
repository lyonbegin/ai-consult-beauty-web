# AI Consult Beauty Web

Frontend for the AI K-Beauty consultation platform.

## Stack
- React
- TypeScript
- Vite

## Product areas
- AI K-Beauty consultation
- Beauty shopping
- Product details / ordering
- Beauty stay
- Airport pickup / mobility
- K-Beauty concierge

The initial frontend is intentionally small and deployment-ready. Existing tourism shopping/stay/mobility modules will be migrated into this repository step by step.
